# Dalanyn Altyny — сайт

Одностраничный сайт бренда «Даланың Алтыны» (джерки, колбаса и тушёнка из конины, Алматы).
Статика без сборки: HTML + CSS + JS, открывается с любого хостинга.

## Что внутри

| Блок | Что происходит при прокрутке |
|---|---|
| Hero | Пакет джерки выезжает в центр, пластины мяса «вылетают» из окна и разлетаются по экрану, появляется «100% мясо». Прокрутка вверх собирает всё обратно в пакет |
| Бегущие строки | Скорость и направление зависят от скорости и направления прокрутки |
| Манифест | Слова «загораются» по мере чтения |
| Продукция | Горизонтальная лента из трёх продуктов на десктопе, вертикальная на телефоне. Упаковки нарисованы в SVG и наклоняются за курсором |
| Колбаса | Нож проходит по колбасе, затем она распадается на кусочки с разрезом |
| Как мы делаем | Золотая линия прорисовывается по шагам |
| Что такое джерки | Слайдер «пустой перекус ↔ настоящее мясо» |
| Знаете ли вы? | Параллакс степи на закате и карточки с фактами со ссылками на источники |
| О бренде | Коллаж фото с параллаксом |
| Подарки, заказ, опрос | Корзина и голосование отправляются в WhatsApp готовым сообщением |
| Instagram, FAQ, подвал | 28 публикаций из профиля, вопросы с разметкой FAQ |

Без анимаций (системная настройка «уменьшить движение» или если не загрузился JS) страница показывается статично и полностью читается.

## Что заменить перед запуском

1. **Домен.** Поиском замените `https://dalanyn-altyny.kz/` на реальный адрес в `index.html`, `robots.txt` и `sitemap.xml`.
2. **Цены (по желанию).** В `assets/js/main.js` в `PRODUCTS` впишите `price: 2500`, и корзина начнёт считать сумму.
3. **Фото.** Сейчас картинки вырезаны из скриншотов Instagram, поэтому качество низкое. Положите оригиналы с теми же именами в `assets/img/` (и в `assets/img/feed/` для ленты).
4. **Проверьте факты:** партнёрство с Vinitaly Kazakhstan Roadshow 2026 (найдено в открытых источниках), наличие в приложении «Рядом», формулировку «Халяль состав».

## Как посмотреть локально

```bash
cd dalanyn-altyny
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

Подойдёт любой статический хостинг: Netlify (перетащить папку), Vercel, GitHub Pages, Cloudflare Pages или обычный хостинг в Казахстане (ps.kz, hoster.kz). Залейте содержимое папки `dalanyn-altyny/` в корень сайта.

## SEO

- `title` и `description` написаны под запросы «джерки из конины», «колбаса из конины Алматы», «халал», «доставка по Алматы».
- JSON-LD: Organization, Store (Алматы), три Product и FAQPage.
- Open Graph-превью `assets/img/og-image.jpg`, favicon, `robots.txt`, `sitemap.xml`, `site.webmanifest`.
- Семантическая разметка, один `h1`, казахский текст помечен `lang="kk"`, у всех фото есть `alt`.

После запуска добавьте сайт в Google Search Console и Яндекс Вебмастер, а ссылку на сайт поставьте в Instagram и в карточку 2GIS.

## Технологии

GSAP 3.12 + ScrollTrigger и Lenis (плавная прокрутка) лежат локально в `assets/js/vendor/`, CDN не нужен. Шрифты Montserrat, Manrope и Cormorant Garamond подключаются из Google Fonts. Логотип переведён в вектор из аватарки профиля.
