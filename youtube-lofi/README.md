# youtube-lofi

Пайплайн сборки длинных музыкальных роликов для YouTube:
обложка + треки → готовый MP4 с описанием и таймкодами.

Ниша пилота — **Lofi / Cozy Rain**.

## Зачем это, если можно склеить в редакторе

Три вещи, которые здесь сделаны и которые обычно пропускают:

1. **Нормализация громкости по EBU R128** (−14 LUFS). Треки из Suno приходят
   с разбросом громкости в 6–8 дБ. Скачок громкости на стыке — самая частая
   причина, по которой слушатель закрывает вкладку.
2. **Кроссфейд между треками.** Тишина на стыке ломает фон, ради которого
   ролик и включили.
3. **Медленный дрейф кадра.** Ролик перестаёт быть JPEG с музыкой —
   и для зрителя, и для политики YouTube об однотипном контенте.

## Установка

```bash
sudo apt-get install -y ffmpeg   # нужны ffmpeg, ffprobe, python3
```

## Использование

```bash
# 1. Положи треки в tracks/ с числовым префиксом — он задаёт порядок:
#      tracks/01-rainy-window.mp3
#      tracks/02-late-study.mp3
#    Имя файла становится названием главы: '01-rainy-window' → 'Rainy Window'.

# 2. Положи обложку в assets/cover.png (16:9, минимум 1920×1080).

# 3. Собери:
./build.sh                      # как есть, с дрейфом кадра
./build.sh --target-hours 2     # зациклить плейлист до ~2 часов
./build.sh --static             # без движения, файл вчетверо легче
./build.sh --crossfade 5        # длиннее переходы между треками
./build.sh --cover my.png       # другая обложка
```

Результат в `out/`:

- `video.mp4` — готов к загрузке (1920×1080, H.264 + AAC 320k, faststart)
- `mix.m4a` — сведённая дорожка, пригодится для Spotify/дистрибуции
- `description.txt` — описание с таймкодами и дисклеймером об ИИ

## Вес файла

Замер на тестовых ассетах (60 секунд), экстраполяция на 2 часа:

| Режим | 60 с | ~2 часа |
|---|---|---|
| дрейф кадра (по умолчанию) | 21 МБ | ~2.5 ГБ |
| `--static` | 5.9 МБ | ~700 МБ |

Разброс в первую очередь задаёт **зернистость обложки**, а не длительность.
В режиме дрейфа каждый кадр слегка отличается от предыдущего, поэтому зерно
и плёночный шум кодируются заново на каждом кадре. Гладкая иллюстрация может
весить вдвое меньше указанного, сильно зернистая — вдвое больше.

Если интернет медленный, есть два рычага: собрать с `--static` (одинаковые
кадры сжимаются в почти пустые P-фреймы) или убрать зерно из обложки перед
сборкой.

## Что здесь НЕ делается

**Музыка.** Её нужно сгенерировать самому в Suno или Udio (нужна платная
подписка — на бесплатном тарифе коммерческое использование запрещено).
Пайплайн начинается с готовых аудиофайлов.

## Тестовые файлы

`tracks/*.mp3` и `assets/cover_placeholder.png` — заглушки для проверки
пайплайна без Suno. Пересоздать их можно так:

```bash
python3 make_test_assets.py
```

Мелодия синтезируется в диапазоне 440-880 Гц, «дождь» — в 800-6000 Гц.
Это сделано намеренно: динамик телефона почти не воспроизводит частоты
ниже ~300 Гц, и тестовый сигнал, построенный на низких тонах, кажется
беззвучным, хотя технически он есть. По той же причине обложка-заглушка
светлая и с крупной надписью — тёмный градиент на экране телефона
неотличим от чёрного кадра.

Перед публикацией замени и то, и другое на настоящие треки и иллюстрацию.
