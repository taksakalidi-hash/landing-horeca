# Библиотека промптов

Личная база промптов по категориям (технологии, бизнес, маркетинг, отношения, кулинария, здоровье и др.).

## Где что лежит
- `prompts/prompts.js` — **сама база**. Категории в `window.CATEGORIES`, промпты в `window.PROMPTS`.
- `prompts/index.html` — страница для выбора: поиск, фильтр по категориям, копирование, избранное, свои промпты.

## Для Claude (как пополнять базу)
Когда пользователь просит «добавь промпты», «пополни базу промптов», «новая категория»:
1. Открой `prompts/prompts.js`.
2. Новый промпт: объект `{ cat, title, tags, text }` в массив `PROMPTS`, в блок нужной категории.
   Подставляемые места пиши в `[квадратных скобках]`.
3. Новая категория: `{ id, name }` в `CATEGORIES`.
4. Закоммить, запушь и переопубликуй артефакт (страница `prompts/index.html` + файл `prompts.js`).
